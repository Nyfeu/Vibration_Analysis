## Ideias principais

1. Apresenta o teste binomial exato para proporções, a base dos testes de sinal e de quantis.
2. Trata também de testes de postos (Kruskal–Wallis, Spearman) e de tabelas de contingência.

## Pontos relevantes para o projeto

- → Projeto: o teste binomial unilateral contra o acaso (1/3) no experimento de montagens: só a regra física acerta mais montagens que o acaso (6 de 9, p = 0,042).
