## Ideias principais

1. Propõe CNNs 1D compactas que aprendem features diretamente do sinal bruto (corrente de motor), sem extração manual.
2. Fundem extração de features e classificação num único modelo, com custo baixo para operação em tempo real.

## Pontos relevantes para o projeto

- → Projeto: motiva a CNN como contraponto às features manuais. Nosso resultado mostra o outro lado: no CWRU, a CNN acerta 99,7% no teste por carga, mas cai para ~50% com uma montagem nova.
