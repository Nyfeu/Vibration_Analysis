## Ideias principais

1. Modela a probabilidade de cada classe por uma função logística de uma combinação linear das variáveis.
2. Trata de estimação por máxima verossimilhança, interpretação dos coeficientes, extensões multinomiais e avaliação do ajuste.

## Pontos relevantes para o projeto
